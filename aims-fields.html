CityU 选课字段解释

集中说明 Master Class Schedule 与 AIMS 中常见的 16 项字段。这里解释字段的通用含义，并标出本站尚未采集的信息。

字段对照表

选班次时优先核对注册编号、剩余名额和完整上课时间。

容易混淆：CRN 是教学班注册编号；Section 是班次编号；WEB 表示网页注册权限，不代表线上授课。

可左右滑动查看完整说明，第一列会保持可见。

CityU Master Class Schedule 常见字段的中文含义与选课说明
英文字段 中文含义 说明
课程与注册
CRNCourse Reference Number 课程注册号 / 教学班注册编号 指定学期内唯一对应一个教学班，选课或退课时用于识别班次；它不是 DSC5001 这类课程代码。
Section 教学班 / 班次编号 通常为 3 位代码，例如 C61。首字母表示教学活动类型，例如 C 为主课、T 为 Tutorial、L 为 Laboratory；它不是 Semester A 或 Semester B。
Credit 学分 课程对应的 Credit Units。学分通常显示在可计分的主课班次；关联的 Tutorial 或 Laboratory 可能显示为 0。
Campus 课程开设 / 授课校区 表示课程开设或授课所在的校区，不能仅根据教学楼字段推断。本站当前未采集此字段。
WEB 网页注册权限 Y 表示通常可通过 Web Add/Drop 加退选；N 表示不能按一般网页流程注册，通常需要联系课程或学术单位处理。它不表示线上课程。
Level 适用学生层级 表示哪些学生层级可以选修，例如 UG 或 PG。它不是本站学生评价中的推荐等级。本站当前未采集此字段。
名额与候补
Avail 剩余可注册名额 快照时点单个 Section 尚余的名额。数值会变化，也不代表学生一定满足课程或项目注册限制。本站班次数据按单个 Section 存储，课程索引中的 summary 为各班次合计。
Cap 教学班容量 单个 Section 允许注册的最大人数。本站班次数据按单个 Section 存储，课程索引中的 summary 为各班次合计。
Waitlist Avail 候补是否可用 / 剩余候补容量 课程级可能显示 Y、N 或 FULL；班次级可能显示数字、N 或 FULL。数字表示该班次剩余候补名额，Y 只表示课程可加入候补，不是人数。本站当前未采集此字段。
上课安排
Date 上课日期范围 表示该教学班实际授课的起止日期，不是选课开放日期或加退选截止日期。
Day 上课星期 例如 M / T / W / R / F / S，本站分别显示为周一至周六；其中 R 表示星期四。
Time 上课时间 例如 09:00 - 11:50。本站课表以香港时间 GMT+8 展示。
BldgBuilding 教学楼 Building 的缩写，显示教学楼名称或代码，例如 BOC、LI、LAU。
Room 教室 具体教室或房间编号，例如 R4057、3505。
Instructor 授课教师 任课教师姓名；可能同时列出多位教师，TBA 表示尚未公布。
Medium of Instruction 授课语言 / 教学媒介 例如 English 或 Chinese。Master Class Schedule 中的信息用于一般参考，具体要求以课程 syllabus 为准。

使用时请注意

字段解释参考 CityU 官方资料，核对日期为 2026-08-11。课程名额和注册状态会持续变化，最终请以 AIMS 为准。
