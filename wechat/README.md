# CityU DS 微信小程序

这是课程查询站的微信小程序工程。微信开发者工具应导入本目录（`wechat/`），工具会根据 `project.config.json` 将 `miniprogram/` 识别为小程序源码根目录。

## 主体与实现边界

本工程按个人主体小程序设计，不使用 `web-view`。首页、课程列表、课表、课程详情、选课字段解释和课程介绍均已实现为微信原生页面。当前同步网页版 2026/27 学年 27 门课程；27 份课程 PDF 已转换为 180 张离线 JPEG 页图，课程介绍每次只显示一页英文原文及其对应中文翻译，可前后翻页。

所有数据科学课程统一使用 `DSC` 前缀。课程数据包含 Semester A、Semester B 和 Summer Term 三学期字段；进入某学期后只展示并安排该学期开设的课程。DSC6002 在 Summer Term 虽无可选班次，仍可无班次加入，并按核心课 1 门 3 学分计入；其 Semester B 班次仍为 D61（CRN 11818），不会复制到 Summer Term。

小程序按学期分别保存 A、B、S 三份课表；首次进入 Semester A 会默认选择 DSC5001、DSC5002、DSC5003 的指定班次，Semester B 和 Summer Term 初始为空，用户清空后不会自动恢复。汇总区统计三个学期的必修、选修、项目与总学分。CS6290、DSC6017、DSC6032 的跨学期选课条件，以及 DSC6017 与 DSC6032 的互斥规则，与网页版保持一致。小程序不提供 TXT 课表导入或导出功能。

小程序导航、课程数据和文档路径统一使用 `DSC`；课程页图保留官方 PDF 原件内容，原件中可能仍印有 `SDSC` 历史学科代码。

小程序工程完全位于 `wechat/`，不会替换或修改仓库根目录中的现有网页版。两者可以并列维护和发布。

不要在小程序代码、配置或仓库中保存 AppSecret、云 API 密钥等服务端凭据。

## 导入开发者工具

1. 安装并打开微信开发者工具，选择“小程序”与“导入项目”。
2. 项目目录选择本仓库下的 `wechat/`，不要直接选择 `miniprogram/`。
3. 在开发者工具中确认 `project.config.json` 的 AppID 属于你要发布的小程序；如果复制本项目用于其他小程序，请替换为自己的 AppID。
4. AppID 可以公开，但 `project.private.config.json` 属于本机开发者工具配置，根目录 `.gitignore` 已将其排除；AppSecret 永远不能写入前端工程或提交到仓库。
5. 如果开发者工具提示缺少 sitemap，请确认 `miniprogram/app.json` 的 `sitemapLocation` 指向 `sitemap.json`。

## 离线图片与分包

课程教学大纲的离线页图会显著增大代码包。本工程已将每门课程的预览页面和页图放进同一个课程分包，并在 `app.json` 的 `subPackages` 中逐项声明；进入课程介绍时才加载对应分包。

当前结构为：

- 主包保留四个 TabBar 页面、课程详情公共代码、课程数据与翻译。
- 27 个文档分包分别保存课程预览页及其 150 dpi JPEG 页图。
- 当前共 180 页；文档分包合计约 24.65 MiB，最大文档分包约 1.28 MiB，主包约 531.7 KiB，源码合计约 25.20 MiB。
- `wechat/generated/pdf-pages-manifest.json` 记录每页路径、尺寸、文件大小和原 PDF 哈希。

微信当前限制为：单个主包或分包不能超过 2M；整个小程序所有分包合计不能超过 30M，服务商代开发的小程序不能超过 20M。项目内的校验脚本会检查这些限制；提交前应运行校验，并在开发者工具的“代码质量/代码依赖分析”或上传界面复核实际编译包体。

若以后替换或新增 PDF，请在仓库根目录执行：

```powershell
node wechat\tools\build-data.mjs
python wechat\tools\render-pdf-pages.py
node wechat\tools\build-document-packages.mjs
node wechat\tools\validate-project.mjs
```

PDF 转图脚本需要本机安装 `PyMuPDF` 与 `Pillow`。当前页图已经生成，普通导入、预览和发布不需要安装这些 Python 依赖。

## 首页与项目支持

- 首页展示 CityU DS Only Logo、课程数量、课程介绍数量、课程/课表/说明页入口，以及可复制的 PC 网页版地址。
- 说明页的“赞赏与支持”用于邀请用户在 GitHub 为项目点亮 Star，完全自愿且不影响任何功能。
- 个人主体小程序无法可靠地直接打开任意 GitHub 网页，因此按钮会复制 `https://github.com/fluffywood/cityuds`，用户可随后在手机浏览器中打开。

## 课表视图

- 课程页和课表页均可切换 Semester A、Semester B 与 Summer Term；每个学期只显示当期开设课程，三个学期的选择分别保存在当前微信设备中。
- 说明页提供原生“选课字段解释”页面，集中说明 CRN、Section、WEB、名额、时间与授课信息。
- 普通课表页会直接展示周一至周六的整周大课表；若已选课程发生时间重叠，会列出具体冲突课程组合和重叠时段，并用红色样式标出对应课程块。
- 点击冲突组合下方的“调整班次和时间”按钮（或红色课程块）可打开班次调整弹窗，上下查看并选择两门冲突安排的新班次和时间；同一课程涉及多组冲突时，可在弹窗顶部切换要处理的组合。
- 点击“确定并更新”后，两项选择会一起保存并立即重绘课表；点击“取消”不会更改原有班次。没有冲突的课程块仍会进入课程详情。
- 原有的按天课程详情仍然保留，可通过“展开按天详情”按需查看，课程班次与 Tutorial 也可继续在同一页面修改。
- 点击清空按钮旁的“完整课表概览”可进入横屏单屏视图，在一个手机屏幕内查看整周安排；点击课程块可查看完整时间、地点和冲突信息。

## 真机预览与发布

1. 换成真实 AppID，并确认小程序管理员、服务类目和小程序备案信息已准备完成。
2. 在开发者工具中清缓存后重新编译，处理所有分包、路径和 sitemap 错误。
3. 使用“预览”生成二维码，分别在 iOS 和 Android 微信中测试首页、搜索、课程详情、分包首次下载、离线页图清晰度及返回操作。
4. 在弱网和无网状态下验证已设计为离线可用的页面；游客 AppID 不能替代此步骤。
5. 使用“上传”提交版本，填写清晰的版本号和功能说明。
6. 登录微信公众平台提交代码审核。名称、简介、服务类目和实际功能需保持一致；若存在登录或受限页面，应提供可体验完整功能的审核账号。
7. 审核通过后发布正式版，并再次进行真机回归测试。
